Правило у всех девяти одно: ребёнок отвечает раньше, чем узнаёт исход.
Меняется только то, откуда берётся неизвестность — из случая, из времени, из собственной уверенности или из соседа по парте.

Как поменять тему

Во всех девяти файлах задания лежат в одном и том же месте: массив QUESTIONS в самом начале <script>. Формат простой — prompt (что показать), answer (правильный ответ, для учителя), hint (правило, которое всплывает после ошибки).

Замени список — и та же игра работает на неправильных глаголах английского, таблице умножения, падежах, столицах, чём угодно. Механику трогать не нужно. Игры не ломаются, если заданий 8 или 40.

Пара мелочей

  • Кнопка 🔊 / 🔇 есть в каждой игре, состояние запоминается.
  • Проверяет ответ учитель — кнопки ✅ / ❌. Ребёнок отвечает вслух, это принципиально.
  • Файлы полностью автономны: можно кинуть в мессенджер, положить на флешку, открыть без интернета.
  • Если в системе включено «уменьшить движение», тряска и разлёт частиц выключаются сами.
